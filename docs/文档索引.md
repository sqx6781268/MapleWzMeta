重新取数方法见 [09-验证基线与已知缺陷.md](09-验证基线与已知缺陷.md)。

## 文档书写约定

- 引用实现路径统一写成 `包/文件.go:行号`，例如 `internal/scan/scan.go:219`（`process` 函数）。
- "实测"= 本机数据集上跑出来的数字；"惯例"= MapleStory WZ 的通用约定，本数据集**未必**符合，
  两处不一致时以实测为准，并在文档里显式标注。
- 数字后面带测量口径（例如"XML 文件数"按 `-name '*.xml'` 统计），便于复现。
- 代码里的注释只写"为什么"，本目录写"是什么、怎么用"；两者不重复内容。

## 一句话概览

把 WZ 导出的 **62,380 个 img XML** 解析成节点树 → 打平 `uol` 引用 → 认出 7~8 位物品 ID →
以 **8 位零填充 ID 为主键**把「名称/描述（来自 `String.wz`）」和「属性（来自 `Item.wz`、`Character.wz`）」
关联成一行，写入按**语言分域**的 SQLite（`data/mia.db`），再由单二进制同时提供命令行检索与内置 HTTP 查询页。
