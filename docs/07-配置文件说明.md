# 07 · 配置说明（`wzconfig.json`）

实现：`internal/config/config.go`。这是**唯一**的配置来源——WZ 目录、SQLite 路径、监听地址、
并发数、图标开关、语言清单全在这里，命令行只保留筛选与临时覆盖项。

## 1. 加载顺序

```
Load(path)
 ├─ path == "" → 探测当前目录下的 ./wzconfig.json
 │        └─ 也不存在 → 用 Default()（内置默认值），仍然执行 resolve()
 ├─ 读文件 → stripLineComments（丢弃以 // 开头的整行）
 ├─ json.Decoder + DisallowUnknownFields  ← 写错字段名会直接报错，不会静默忽略
 ├─ cfg.Path = 配置文件绝对路径
 ├─ mergeDefaults()  ← 空字段回填默认
 ├─ resolve()        ← 相对路径按“配置文件所在目录”转绝对
 └─ validate()       ← 语言标识合法性 / 重复 / 目录存在性
```

（`internal/config/config.go:149` `resolve`，接收者必须是指针，否则改写只落在副本上）。
因此从任意目录用 `-config D:\ASM\MapleWzMeta\wzconfig.json` 启动都能取到同一套数据。

## 2. 字段总表

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `db` | string | `./data/mia.db` | SQLite 路径，父目录自动创建 |
| `addr` | string | `127.0.0.1:8080` | `serve` 监听地址；CLI `-addr` 可覆盖 |
| `workers` | int | `0` | 解析协程数；`<=0` 表示取 `runtime.NumCPU()` |
| `icons.enabled` | bool | `false` | **关掉时**：不建索引、不注册 `/img`、页面不显示图标列 |
| `icons.dir` | string | `./imgdata` | 图标来源：**目录**（布局 `<dir>/<Wz>/<类别>/<id>.img.png`）或**打包好的 `.zip`**（同一棵树，读法不同见 [08](08-命令行与查询接口.md) §5） |
| `admin.enabled` | *bool | 开（`null` 视作 `true`） | 关掉时 `/admin` 与 `/api/admin/*` 一律 404 |
| `admin.token` | string | 空 | 非空时所有 `/api/admin/*` 都要带 `X-Admin-Token`；**留空则只放行本机回环地址** |
| `locales` | array | 单个 `zh-CN` 条目 | 语言包清单，**一个条目 = 一套语言目录** |
| `locales[].lang` | string | — | 语言标识，入库作 `item.lang`；须匹配 `^[A-Za-z0-9][A-Za-z0-9_-]{1,19}$`（2–20 位） |
| `locales[].label` | string | 等于 `lang` | 界面显示名 |
| `locales[].sources` | string[] | `DefaultSources` | 参与关联的 `.wz`；留空即用 `["String.wz","Item.wz","Character.wz","Mob.wz","Npc.wz"]`（`internal/config/config.go:22`） |

`Path` 字段带 `json:"-"`，由 `Load` 填入，配置文件里写了会被 `DisallowUnknownFields` 拒绝。

## 3. 注释支持
配置里允许**整行** `//` 注释（`internal/config/config.go:252`）：

```jsonc
{
  // 只在行首（允许前置空白）生效；行尾 // 会被当作字符串内容
  "db": "data/mia.db",
  "addr": "127.0.0.1:8080"
}
```

限制：不支持块注释 `/* */`，不支持行尾注释。写说明请单独占一行。

## 4. 现网配置（仓库根 `wzconfig.json`）

```jsonc
{
  "db": "data/mia.db",
  "addr": "127.0.0.1:8080",
  "workers": 0,
  "icons": { "enabled": true, "dir": "imgdata" },
  "admin": { "enabled": true, "token": "" },
  "locales": [
    { "lang": "zh-CN", "label": "简体中文", "wz": "wz",
      "sources": ["String.wz", "Item.wz", "Character.wz", "Mob.wz", "Npc.wz"] }
  ]
}
```

注意 `wz` 写的是 `wz`（相对配置文件目录），与主 `String.wz` 内容已是中文这一事实一致；
`sources` 现在带 `Mob.wz`、`Npc.wz` 两个包，怪物与 NPC 的属性就是从它们抽的（名称侧仍来自 `String.wz/{Mob,Npc}.img.xml`）。
`wz-zh-CN/` 目前只导出 `String.wz`（20 张表）/`Etc.wz`/`Quest.wz`（合计 51 个 XML），**未配成独立 locale**——
若把它当独立语言扫入，会得到一份只有名称、几乎没有属性的残缺域，反而拉低覆盖率。

## 5. 管理页（`admin`）

管理页要改库，所以闸门只有两条，实现见 `internal/web/admin.go` 的 `adminGuard`：

| 配置 | 判定 |
|---|---|
| `admin.token` 非空 | 请求头 `X-Admin-Token` 必须完全相等，否则 **401** |
| `admin.token` 为空 | 只允许**对端地址是回环**（`127.0.0.0/8`、`::1`）的请求，否则 **403** |
| `admin.enabled=false` | `/admin` 页面和全部 `/api/admin/*` 都 **404**，等于没这个功能 |

- 页面本身（`GET /admin`）**不鉴权**，静态 HTML 里没有数据；真正的读接口 `/api/admin/diff` 等全部要过闸门。
- 首页右上角的「管理页」入口由 `/api/stats` 的 `adminOn` 控制：`admin.enabled=false` 时链接不渲染，不留 404 死链。
- 口令在页面顶部输入，存 `localStorage`，只随 `X-Admin-Token` 头发送；**没有会话、没有 cookie**。
- 因此把 `addr` 绑到 `0.0.0.0` 或局域网地址时**必须设 `token`**，否则同网段任何人都能改库。
- `token` 写在配置文件里，`wzconfig.json` 是入库跟踪的，**不要把真实口令提交上去**。

## 6. 多语言规则

| 场景 | 做法 |
|---|---|
| 加一门语言 | 在 `locales` 追加一项，指向该语言的导出目录；只改配置，无需改代码 |
| 只扫某一语言 | `maplewzmeta scan -lang zh-CN`（逗号分隔多个；`all` = 全部） |
| 查询切语言 | `?lang=` / CLI `-lang`；缺省用 `locales[0]`（`DefaultLang()`） |
| 数据隔离 | `item`/`npc`/`mob`/`wz_file` 主键都以 `lang` 打头，**不同语言互不覆盖** |
| 图标 | 与语言无关，**全局只配一份**，不落库；但取图按实体域限定来源目录 |

`-lang` 传了未配置的值会报错并列出可选项：`未配置的语言 "en"，可选：zh-CN`。

### 6.1 为什么不做"整文件中英覆盖合并"

外部笔记（BeiDou gms-server 的 `LocalizedDataProvider`）的多语言做法是**按整文件回退**：
语言目录里有同名 XML 就整份用它，缺哪个文件才回退到英文基础。本项目**不做这层合并**，理由是实测：

- 本机 `wz-zh-CN/` 只导出了 51 个 XML（`String.wz` 全部 20 张表 + `Etc.wz` + `Quest.wz`），
  且抽查 `String.wz/{Mob,Npc,Eqp}.img.xml` 与主 `wz/` 下同名文件 **md5 完全相同**——
  实现了覆盖合并也是 no-op。
- 真要接第二门语言时，各语言各自成一个 locale、各扫各的 `data/mia.db`（按 `lang` 分域），
  比在解析层再叠一层文件级回退更简单，也天然隔离。

（`internal/wzxml/uol.go:28` `ResolveUol`）已覆盖同等能力，无需另做。

## 7. 校验规则与典型报错
`validate()`（`internal/config/config.go:174`）逐条检查：

| 情况 | 报错 |
|---|---|
| `lang` 不匹配正则 | `locales[0].lang "CN_CN" 不合法（2-20 位字母数字/_/-）` |
| `lang` 重复 | `locales[1].lang "zh-CN" 重复` |
| `wz` 为空 | `locales[0].wz 不能为空` |
| `wz` 目录不存在 | `locales[0]（zh-CN）的 wz 目录不存在或不是目录: …` |
| `icons.enabled=true` 但来源缺失 | `icons.enabled 为 true，但 icons.dir 不存在: …`（目录与 zip 同等对待，只要求存在） |
| 字段名写错 | JSON 解析失败并带 `json: unknown field "…"` |

**图标是可选的**：`enabled: true` 时目录必须存在（宁可启动即报错，也不要页面上半屏碎图）。

## 8. 覆盖优先级

| 项 | 来源优先级 |
|---|---|
| DB 路径 | `-db`（各子命令都有）> 配置 `db` > 默认 |
| 监听地址 | `-addr` > 配置 `addr` > 默认 |
| 参与扫描的语言 | `-lang` 选择 `locales` 子集 |
| 并发数 | 仅配置 `workers`（无 CLI 覆盖） |
| `-limit` / `-batch` | 仅 `scan` 有，属临时调试参数，不写进配置 |

## 9. 改配置的验证步骤

```bash
go test ./internal/config/          # 覆盖：缺文件回落默认、相对路径按配置目录解析、非法配置被拒
go build -o bin/maplewzmeta.exe ./cmd/maplewzmeta
./bin/maplewzmeta.exe stats         # 最快确认：能否打开库、图标索引规模、各语言域概况
./bin/maplewzmeta.exe scan -limit 50 # 小批量确认管线没被路径改坏
```

测试见 `internal/config/config_test.go`（`TestLoadResolvesRelativeToConfigDir` 专门锁住"相对路径基准"这条规则）。
