# 08 · 命令行与 HTTP 接口

入口只有一个二进制：`cmd/maplewzmeta/main.go`。四个子命令共用 `wzconfig.json`
（见 [07-配置文件说明](07-配置文件说明.md)），命令行只保留**筛选**与**临时覆盖**参数。

```bash
go build -o bin/maplewzmeta.exe ./cmd/maplewzmeta
./bin/maplewzmeta.exe              # 打印用法
```

## 1. 子命令

| 子命令 | 作用 | 实现 |
|---|---|---|
| `scan` | 按 `locales` 逐个语言扫描入库（增量） | `cmd/maplewzmeta/main.go:78` |
| `query` | 命令行检索单个语言域 | `cmd/maplewzmeta/main.go:124` |
| `stats` | 打印图标索引概况 + 各语言域规模 | `cmd/maplewzmeta/main.go:185` |
| `serve` | 起 HTTP 服务与内置查询页 | `cmd/maplewzmeta/main.go:254` |

### 公共参数

| 参数 | 含义 |
|---|---|
| `-config` | 配置文件路径；留空则探测当前目录 `./wzconfig.json`，再回落内置默认 |
| `-db` | 覆盖配置里的 SQLite 路径（相对路径按**进程工作目录**解析，与配置字段的基准不同） |

### `scan`

```bash
maplewzmeta scan                          # 配置里全部语言
maplewzmeta scan -lang zh-CN              # 只扫一个
maplewzmeta scan -lang zh-CN,en -limit 50 # 多个 + 小批量试跑
```

| 参数 | 默认 | 含义 |
|---|---|---|
| `-lang` | `all` | 选择 `locales` 子集，逗号分隔；未配置的语言直接报错并列出可选项 |
| `-limit` | `0` | **每个语言**最多解析多少个待处理文件，调试用 |
| `-batch` | `400` | 每攒多少文件写一次库 |

每个语言跑完立即打印该域概况（`printStats`，`main.go:225`）；某个语言失败会带上语言标识中断后续语言。
增量判据是 `size + mtime`，因此重跑同一份导出会得到「跳过未变 = 磁盘文件数」。

### `query`

```bash
maplewzmeta query -lang zh-CN -q 药水 -limit 5
maplewzmeta query -prefix 0100 -cat Cap -complete
maplewzmeta query -attr cash=1 -json
```

| 参数 | 含义 |
|---|---|
| `-lang` | 缺省用 `locales[0]`（`DefaultLang()`） |
| `-q` / `-id` / `-prefix` / `-cat` | 名称模糊 / 精确 ID / ID 前缀 / 分类 |
| `-attr key=value` | 属性等值过滤（JSON 路径查询） |
| `-complete` | 只要名称与属性齐全 |
| `-unnamed` | 只要缺名称的——用来核对导出缺口 |
| `-limit` / `-json` | 条数 / 机器可读输出 |

### `stats`

`-lang` 同 `scan`。先打印图标索引（或"未启用"），再逐语言打印规模。

## 2. HTTP 端点

注册于 `internal/web/web.go:43`，全部只读、全部 `GET`：

| 端点 | 参数 | 返回 |
|---|---|---|
| `/` | — | 内置单页（`go:embed static/*`） |
| `/api/items` | `lang,q,id,cat,attr,like,min,max,has,complete,order,desc,limit,offset` | `{items,lang,total,limit,offset}`，`limit` 夹在 1–500 |
| `/api/item` | `lang,id` | 单条详情；不存在返回 404 纯文本 |
| `/api/stats` | `lang` | 该语言域规模 + `iconsOn` |
| `/api/categories` | `lang` | 该语言域分类计数，按数量降序 |
| `/api/meta` | `lang` | 检索页侧边栏一次拿全：`{lang,uncategorized,categories:[{name,label,count}],attrs:[{key,label,kind,preset,count}]}` |
| `/api/langs` | — | `{default,langs:[{lang,label,items,named}]}`，**来自配置**而非库，未扫的语言也会出现且计数为 0 |
| `/api/health` | — | `{"status":"ok"}` |
| `/img/<id>.png` | — | 图标文件；仅在 `icons.enabled` 时注册 |

约定：

- `q` 为纯数字时走 **ID 前缀**，否则走名称模糊（`web.go:345`）。
- 属性条件一律支持重复传，多个条件之间是「且」：
  - `attr=key=value` 等值；`like=key=子串` 包含；`min=key=整数` ≥；`max=key=整数` ≤；`has=key` 只要求键存在。
  - 键名须匹配 `^[A-Za-z0-9_.@-]{1,64}$`，否则 400；含点键（`icon.width`）合法。
  - `min`/`max` 非整数 → 400（`fillRange`，`web.go:401`）。
  - **数值比较要求键存在**：`store` 侧写成 `json_extract(...) IS NOT NULL AND CAST(... AS INTEGER) >= ?`，缺该键的物品不会被当成 0 命中。
- `cat=(未分类)` 是哨兵值，`store.NoCategoryName` 会翻译回 `category = ''`。
- `complete` 取 `all` / `named` / `info`。
- `lang` 不在配置里 → **400**，不回落默认（`web.go:309`）。
- 列表与详情的 `icon` 字段带 `omitempty`：无图或图标关闭时该键根本不出现。
- `/api/meta` 的属性清单来自 `json_each(info)` 全表展开（56k 行约 0.7s），**按语言缓存在进程内**（`Server.attrCache`），只在首次请求该语言时慢一次。
- `/api/meta` 的 `label` 来自 `internal/web/dict.go` 的人工词典：36 个分类、约 95 个属性键有中文名；未收录的键 `label` 回落为原名。
  图标尺寸/锚点这类派生键由 `isNoiseAttr` 直接屏蔽，不进清单。

```bash
curl -s "http://127.0.0.1:8080/api/langs"
curl -s "http://127.0.0.1:8080/api/items?cat=Accessory&limit=3" | tr ',' '\n' | grep '"icon"'
curl -s "http://127.0.0.1:8080/api/items?lang=zh-CN&cat=Weapon&min=reqLevel=100&max=reqLevel=150&attr=cash=0"
curl -s "http://127.0.0.1:8080/api/meta?lang=zh-CN" | tr ',' '\n' | grep '"label"' | head
curl -s -o /dev/null -w "%{http_code} %{content_type}\n" "http://127.0.0.1:8080/img/01000025.png"
```

## 3. 内置查询页

`internal/web/static/index.html`，无构建链、无外部依赖。布局是「顶栏 + 左侧筛选栏 + 右侧结果区 + 详情浮动层」。

| 位置 | 行为 |
|---|---|
| `index.html:92` `<aside>` | 左侧 288px 固定宽度、`position:sticky` 的筛选栏：分类清单、数据完整度、属性条件、排序 |
| `index.html:249` `catLabel()` / `:255` `renderCats()` | 分类显示为 `武器（Weapon）` + 条数，顶部有「筛选分类…」搜索框；`全部分类`、`未分类` 两个哨兵项不再套括号 |
| `index.html:268` `renderConds()` | 属性条件构建器：每行「键 + 运算符（等于/包含/≥/≤/存在）+ 值」，可任意增删；键输入框挂 `datalist#attrKeys`，既能从 307 个真实键里选，也能手输未收录的键，行下方实时提示中文含义 |
| `index.html:290` `renderPresets()` | 词典里 `preset=true` 的常用属性做成快捷按钮，点一下即追加一行条件 |
| `index.html:298` `loadMeta()` | 拉 `/api/meta`，切换语言时重新拉取 |
| `index.html:173` `collectParams()` | 把条件行翻译成 `attr/like/min/max/has` 查询串并始终附带 `lang`（**别写成 `params.toString()` 之类把函数塞进 URL**） |
| `index.html:211` `render()` / `:239` `chips()` | 图标列按 `iconsOn` 动态插入；属性摘要只展示 `preset` 键并显示中文名 |
| `index.html:319` `detail(id)` → `:347` `openModal()` | 详情走右上角带 × 的浮动层（`#modal`，`position:fixed`），点遮罩或按 Esc 同样关闭；**不做任何 `scrollIntoView`** |
| `index.html:317` `NOISE_KEY` | 详情里把 `icon.*`、`iconRaw.*`、`*.origin.x` 等派生字段折进 `<details>`，正文只留业务属性 |

启动顺序是 `loadLangs() → refreshAll()`，保证首个请求就带上正确的 `lang`。

> 分页曾出现「点下一页莫名跳到详情」的假象：根因是 `detail()` 在 `fetch` 返回后调 `box.scrollIntoView()`，
> 异步完成时用户已翻到下页，页面被强行滚回详情。现在详情改浮层且彻底去掉滚动。

## 4. 图标服务

`internal/icons/icons.go`：

- `Build(dir)`（`:42`）遍历 `<dir>/<Wz>/<类别>/<id>.img.png`，ID 经 `extract.NormalizeID` 零填充到 8 位后作键。
- 同 ID 多来源按 `rankOf`（`:81`）取优先级：`Item`=0 > `Character`=1 > 其他（`Npc` 等）=5。
- `Serve`（`:119`）只接受纯数字 ID，路径一律取自索引，因此不存在目录穿越；非法名 400、无此图标 404，命中则带 `Cache-Control: public, max-age=86400`。
- `icons.enabled=false` 时 `web.New(db, cfg, nil)`，`/img` 根本不注册，页面也不渲染图标列——**关掉图标不影响任何数据**。

## 5. 常见故障

| 现象 | 原因与处置 |
|---|---|
| `bind: Only one usage of each socket address` | 8080 上还有旧实例。`netstat -ano \| grep :8080` 取 PID 确认后停掉，或 `-addr 127.0.0.1:8081` 换端口 |
| 页面全碎图 | `icons.dir` 指错目录；启动日志会打印图标索引规模，为 0 即目录不对 |
| 某语言条目为 0 | 该 locale 的 `sources` 没覆盖到含物品 ID 的包，或 `wz` 目录指错 |
| 查询返回整表数据 | 前端把查询串拼错了（历史上曾把函数名序列化进 URL），核对 `collectParams()` |
