# 08 · 命令行与 HTTP 接口

入口只有一个二进制：`cmd/maplewzmeta/main.go`。四个子命令共用 `wzconfig.json`
（见 [07-配置文件说明](07-配置文件说明.md)），命令行只保留**筛选**与**临时覆盖**参数。

```bash
go build -o bin/maplewzmeta.exe ./cmd/maplewzmeta
./bin/maplewzmeta.exe              # 打印用法
```

## 1. 子命令

| 子命令 | 作用 | 实现 |
|---|---|---|
| `scan` | 按 `locales` 逐个语言扫描入库（增量） | `cmd/maplewzmeta/main.go:78` |
| `query` | 命令行检索单个语言域（可指定实体域） | `cmd/maplewzmeta/main.go:130` |
| `stats` | 打印图标索引概况 + 各语言域规模（一个语言下分物品/NPC/怪物三行） | `cmd/maplewzmeta/main.go:197` |
| `serve` | 起 HTTP 服务与内置查询页 | `cmd/maplewzmeta/main.go:277` |

### 公共参数

| 参数 | 含义 |
|---|---|
| `-config` | 配置文件路径；留空则探测当前目录 `./wzconfig.json`，再回落内置默认 |
| `-db` | 覆盖配置里的 SQLite 路径（相对路径按**进程工作目录**解析，与配置字段的基准不同） |

### `scan`

```bash
maplewzmeta scan                          # 配置里全部语言
maplewzmeta scan -lang zh-CN              # 只扫一个
maplewzmeta scan -lang zh-CN,en -limit 50 # 多个 + 小批量试跑
```

| 参数 | 默认 | 含义 |
|---|---|---|
| `-lang` | `all` | 选择 `locales` 子集，逗号分隔；未配置的语言直接报错并列出可选项 |
| `-limit` | `0` | **每个语言**最多解析多少个待处理文件，调试用 |
| `-batch` | `400` | 每攒多少文件写一次库 |
| `-force` | `false` | 忽略 `size + mtime` 指纹，全部重解（补齐 `wz_file.ids` 时用） |
| `-overwrite` | `false` | 落库改为"以文件为准"：`info` 整包替换、并清掉该文件不再贡献的 ID |

两个开关**互相独立**：`-overwrite` 只改落库语义，仍按增量挑文件；要"全部重解且以文件为准"就同时给
`-force -overwrite`（管理页的重载固定给 `-force` 等价的 `Force: true`，是否覆盖由页面上的开关决定）。
手工改过的行（`item.edited=1`）在命令行**始终受保护**（`SkipEdited: true` 写死），
管理页则额外给了开关「同时覆盖手工修改过的行」。

每个语言跑完立即打印该域概况（`printStats`，`main.go:244`，一个语言下分物品/NPC/怪物三行）；
某个语言失败会带上语言标识中断后续语言。
增量判据是 `size + mtime`，因此重跑同一份导出会得到「跳过未变 = 磁盘文件数」。

### `query`

```bash
maplewzmeta query -lang zh-CN -q 药水 -limit 5
maplewzmeta query -prefix 0100 -cat Cap -complete
maplewzmeta query -attr cash=1 -json
maplewzmeta query -kind mob -q 僵尸蘑菇        # 查怪物域
maplewzmeta query -kind npc -id 1012100        # 查 NPC 域（id 自动补零）
```

| 参数 | 含义 |
|---|---|
| `-kind` | 实体域：`item` / `npc` / `mob`，缺省 `item`（`main.go:134`；非法值直接报错退出） |
| `-lang` | 缺省用 `locales[0]`（`DefaultLang()`） |
| `-q` / `-id` / `-prefix` / `-cat` | 名称模糊 / 精确 ID / ID 前缀 / 分类（`-id`/`-prefix` 会先补零到 8 位） |
| `-attr key=value` | 属性等值过滤（JSON 路径查询，按所选域的 `info` 键生效） |
| `-complete` | 只要名称与属性齐全 |
| `-unnamed` | 只要缺名称的——用来核对导出缺口 |
| `-limit` / `-json` | 条数 / 机器可读输出（JSON 里带 `kind` 字段） |

### `stats`

`-lang` 同 `scan`。先打印图标索引（或"未启用"，图标按物品/NPC/怪物三域分别计数），
再逐语言打印规模：每个语言下**分三行输出物品 / NPC / 怪物的条数与有名称/有属性/齐全占比**，
末尾的文件数是语言域级别的合计。

## 2. HTTP 端点
注册于 `internal/web/web.go:59`，全部只读、全部 `GET`。**除 `/api/langs`、`/api/health` 外的检索端点一律带 `kind` 查询参数**
（`item`/`npc`/`mob`，缺省即物品域保持向后兼容，显式传陌生值 400，`internal/web/web.go:149` `kindOf`）：

| 端点 | 参数 | 返回 |
|---|---|---|
| `/` | — | 内置单页（`go:embed static/*`） |
| `/api/items` | `kind,lang,q,id,cat,attr,like,min,max,has,complete,order,desc,limit,offset` | `{items,lang,kind,total,limit,offset}`，`limit` 夹在 1–500；行对象带 `kind` |
| `/api/item` | `kind,lang,id` | 单条详情，**额外带 `stringFiles` / `infoFiles`**（名称侧与属性侧各自的来源文件）；不存在返回 404 纯文本 |
| `/api/stats` | `kind,lang` | 该实体域 + 语言域规模（回包含 `kind`）+ `iconsOn`（图标是否开）+ `adminOn`（管理页是否启用，首页据此显示管理入口） |
| `/api/categories` | `kind,lang` | 该实体域 + 语言域分类计数，按数量降序 |
| `/api/meta` | `kind,lang` | 检索页侧边栏一次拿全：`{lang,kind,uncategorized,categories:[{name,label,count}],attrs:[{key,label,kind,preset,count}]}`；属性中文说明按域查（见下） |
| `/api/langs` | — | `{default,langs:[{lang,label,items,named}]}`，**来自配置**而非库，未扫的语言也会出现且计数为 0（规模列是物品域口径） |
| `/api/health` | — | `{"status":"ok"}` |
| `/img/<id>.png` | `for` | 图标文件；`for=<kind>` 决定允许的来源目录（缺省即物品域），仅在 `icons.enabled` 时注册 |

约定：
- `q` 为纯数字时走 **ID 前缀**，否则走名称模糊（`internal/web/web.go:420`）。
- 属性条件一律支持重复传，多个条件之间是「且」：
  - `attr=key=value` 等值；`like=key=子串` 包含；`min=key=整数` ≥；`max=key=整数` ≤；`has=key` 只要求键存在。
  - `min`/`max` 非整数 → 400（`fillRange`，`internal/web/web.go:474`）。
  - **数值比较要求键存在**：`store` 侧写成 `json_extract(...) IS NOT NULL AND CAST(... AS INTEGER) >= ?`，缺该键的行不会被当成 0 命中。
- `cat=(未分类)` 是哨兵值，`store.NoCategoryName` 会翻译回 `category = ''`。
- `lang` 不在配置里 → **400**，不回落默认（`internal/web/web.go:377`）。
- `kind` 传陌生值 → **400**（`kind 只能是 item / npc / mob`）；不传即按物品域，兼容旧链接与脚本。
  **物品域之外的行，`icon` 会自动带上 `?for=<kind>`**（`toView`，`internal/web/web.go:131`），保证取到自己域的图。
- `stringFiles` / `infoFiles` **只在 `/api/item` 出现，列表接口不带**：反查要把 5.5 万行 `wz_file.ids` 做 `json_each` 展开，单次约 0.25s，摊到每页 500 行会把响应拖成分钟级。前端用它渲染详情浮层底部的"名称来自 / 属性来自"，某侧为空即说明该侧没有文件认领（多数是属性侧没导出）。
- `/api/meta` 的属性清单来自 `json_each(info)` 全表展开（**按 `kind|lang` 缓存**在进程内，`Server.attrCache`），只在首次请求该域该语言时慢一次。
- `/api/meta` 的 `label` 来自 `internal/web/dict.go` 的人工词典，**按实体域分表**：物品 `attrTable`（`dict.go:61`，全局兜底）、
  怪物 `attrTableMob`（`dict.go:172`）、NPC `attrTableNPC`（`dict.go:211`），经 `attrMetaFor(kind,key)`（`dict.go:251`）查找——
  同一个键在两个域语义不同（`undead` 装备上是"对不死族伤害"、怪物上是"不死族属性"；`link` 怪物上是"外观复用哪个怪"）。
  未收录的键 `label` 回落为原名；图标尺寸/锚点这类派生键由 `isNoiseAttr` 屏蔽，不进清单。

```bash
curl -s "http://127.0.0.1:8080/api/langs"
curl -s "http://127.0.0.1:8080/api/items?cat=Accessory&limit=3" | tr ',' '\n' | grep '"icon"'
curl -s "http://127.0.0.1:8080/api/items?lang=zh-CN&cat=Weapon&min=reqLevel=100&max=reqLevel=150&attr=cash=0"
curl -s "http://127.0.0.1:8080/api/meta?lang=zh-CN" | tr ',' '\n' | grep '"label"' | head
curl -s -o /dev/null -w "%{http_code} %{content_type}\n" "http://127.0.0.1:8080/img/01000025.png"
```

## 3. 管理接口与管理页

实现：`internal/web/admin.go`（端点）+ `internal/web/static/admin.html`（页面，同样 `go:embed`）。
**改页面必须重新编译二进制**，刷新浏览器是没用的。

访问闸门见 [07 · 管理页（admin）](07-配置文件说明.md)：`admin.token` 非空查 `X-Admin-Token` 头，
留空则只放行回环地址；`admin.enabled=false` 时这些端点全部 404。

入口有三处，等价：直接访问 `/admin`、`serve` 启动日志里打印的地址、**首页页头右侧的「管理页」链接**
（后者由 `/api/stats` 的 `adminOn` 控制显隐，关掉管理页时链接一并消失，不会留一个 404 死链）。

| 端点 | 方法 | 参数 | 作用 |
|---|---|---|---|
| `/api/admin/diff` | GET | `lang,state,limit` | 磁盘指纹 ↔ `wz_file` 四态比对，回 `new/changed/gone/unchanged` 计数 + 明细 + `provenance` + `editedRows`（三域合计）+ `editedByKind`（`{item,npc,mob}` 分域明细，`handleAdminDiff`，`internal/web/admin.go:292`） |
| `/api/admin/reload` | POST | `lang`，体 `{paths[],selector,all,merge,overwriteEdited}` | 提交后台重载任务，**202** 回 `{jobId,target}` |
| `/api/admin/prune` | POST | `lang`，体 `{overwriteEdited}` | 清掉磁盘上已不存在的文件记录及其**独占**贡献 |
| `/api/admin/job` | GET | — | 当前/上一个后台任务的状态与进度 |
| `/api/admin/files` | GET | `lang,q,status,limit,offset` | 分页列 `wz_file`，`q` 是路径子串（`%`、`_` 按字面量处理） |
| `/api/admin/sources` | GET | `kind,lang,id` | 反查某个实体由哪些文件贡献（管理页"只重解析来源文件"用）。**必须带 `kind`**：物品与怪物同 ID 重叠，不带域会把 `Mob.wz` 的文件列成物品来源（`handleAdminSources`，`internal/web/admin.go:249`） |
| `/api/admin/item` | POST | `kind,lang`，体 `{id,name,descr,category,info,edited}` | 手工改一行；**行不存在直接 404，不会凭空建**（`handleAdminItem`，`internal/web/admin.go:113`） |
| `/api/admin/item` | DELETE | `kind,lang,id` | 删一行实体（按 `kind` 定位表，`internal/web/admin.go:184`） |

`reload` 的目标解析优先级是 `paths` > `selector`（服务端现算一次 diff 再 `SelectedPaths`）> `all`：

- `paths`：精确文件列表，也接受以 `/` 结尾的**目录前缀**（`scan.pickByPath`）。清单里没匹配到的路径回在 `job.missing` 里提示。
- `selector`：`new` / `changed` / `gone` 用 **`+`** 连接（`store.SelectedPaths` 按 `+` 拆分），如 `new+changed`。
- `all`：不传 `Paths`，由 `scan` 自己枚举全库（此时 `target` 一开始是 0，靠 `OnProgress` 回调补上真实总数）。
- `merge=true` 退回"只增不减"的旧语义（不加 `info` 整包替换、不清失效贡献）。

后台任务是**单飞**的：`startJob` 发现已有 `running` 就回 **409**。页面每 1.2 秒轮询 `/api/admin/job`，
进度条按 `done/target` 计算，任务完成后自动重新比对一次。

管理页 `internal/web/static/admin.html` 顶栏也有**实体域下拉**（`admin.html:59` `#kind`，`curKind()` `:172`）：
物品修正页的读 / 存 / 删与来源反查都带 `kind`（`doItems()` `:328`、POST `:379`、DELETE `:393`、
sources 反查 `:410`）；换域会先关掉旧编辑面板再刷新（跨域同 ID 会撞车，`:371`）。
比对页的手工行统计除总数外还显示 `物品 / NPC / 怪物` 分域明细（`editedByKind`，`doDiff()` `:235` 渲染于 `:241`）。

```bash
# 口令模式下手工比对与重载
curl -s -H "X-Admin-Token: <token>" "http://127.0.0.1:8080/api/admin/diff?lang=zh-CN"
curl -s -X POST -H "X-Admin-Token: <token>" -d '{"paths":["Item.wz/Etc/0430.img.xml"]}' \
     "http://127.0.0.1:8080/api/admin/reload?lang=zh-CN"
```

## 4. 内置查询页

`internal/web/static/index.html`，无构建链、无外部依赖。布局是「顶栏 + 左侧筛选栏 + 右侧结果区 + 详情浮动层」。

| 位置 | 行为 |
|---|---|
| `index.html:106` 顶栏「实体」下拉 `#kind` | 物品 / NPC / 怪物三选；切域会清掉分类选中、重拉语言计数并 `refreshAll()`（`index.html:430`）；`curKind()` `:202`、中文名 `kindName()` `:204` |
| `index.html:116` `#adminLink` → `:349` `loadStats()` | 页头右侧的「管理页」入口，指向 `/admin`；只在 `/api/stats` 返回 `adminOn=true` 时显示（`admin.enabled=false` 时 `/admin` 是 404，不留死链） |
| `index.html:120` `<aside>` | 左侧 288px 固定宽度、`position:sticky` 的筛选栏：分类清单、数据完整度、属性条件、排序 |
| `index.html:121` `#catBlock` | 分类筛选块；**在 NPC / 怪物域下整块隐藏**（`loadMeta()` `:337`：`Mob.wz`/`Npc.wz` 一文件一实体、没有分类目录，留着只有一个"(未分类)"没意义） |
| `index.html:288` `catLabel()` / `:294` `renderCats()` | 分类显示为 `武器（Weapon）` + 条数，顶部有「筛选分类…」搜索框；`全部分类`、`未分类` 两个哨兵项不再套括号 |
| `index.html:307` `renderConds()` | 属性条件构建器：每行「键 + 运算符（等于/包含/≥/≤/存在）+ 值」，可任意增删；键输入框挂 `datalist#attrKeys`，既能从域内真实键里选，也能手输未收录的键，行下方实时提示中文含义 |
| `index.html:329` `renderPresets()` | 词典里 `preset=true` 的常用属性做成快捷按钮，点一下即追加一行条件（按当前实体域出，怪物域出 `level`/`maxHP`… 而非物品域的 `reqLevel`…） |
| `index.html:337` `loadMeta()` | 拉 `/api/meta`，带当前 `kind`；切语言或切实体域时重新拉取 |
| `index.html:210` `collectParams()` | 把条件行翻译成 `attr/like/min/max/has` 查询串，始终附带 `lang` 与 `kind`；**只有物品域才带 `cat`**（`:216`） |
| `index.html:250` `render()` / `:278` `chips()` | 图标列按 `iconsOn` 动态插入；非物品域的图标 URL 带 `?for=<kind>`；属性摘要只展示 `preset` 键并显示中文名 |
| `.tablecard` / `.tablewrap` | 表格与分页装在**同一张固定高度的卡片**里（`height:calc(100vh - 210px)`）：表格在卡片内部滚动、表头吸顶，分页条钉在卡片底部，翻页不必把整页滚到底。这里必须是 `height` 而不是 `min-height`——只给下限会被 50 行内容撑高，内部滚动永远不触发 |
| `#pages` + `pageList()`（`index.html:285`，窗口宽度 `PAGE_WINDOW=5` 在 `:283`）/ `renderPages()`（`:294`） | 分页条**最左边是页码**：固定首页 `1` + 当前页**前后各 5 页** + 固定末页，中间空档渲染成 `…`，当前页高亮；点页码只改 `offset` 再 `run()`，**不滚动页面也不弹详情**。总页数按当前「每页」条数现算，改每页条数后旧页码越界会被夹回最后一页（`:517`） |
| `td.chips` + `.chipwrap` | 关键属性列由 `table-layout:fixed` 限定为剩余宽度（名称列固定 170px，不再被挤成竖排），内部允许换行但**最多显示 3 行**（`-webkit-line-clamp:3`），超出截断并保留末尾「…另 N 项」，全量看详情浮层 |
| `index.html:364` `detail(id)` → `:402` `openModal()` | 详情走右上角带 × 的浮动层（`#modal`，`position:fixed`），点遮罩或按 Esc 同样关闭；**不做任何 `scrollIntoView`** |
| `index.html:362` `NOISE_KEY` | 详情里把 `icon.*`、`iconRaw.*`、`*.origin.x` 等派生字段折进 `<details>`，正文只留业务属性 |

启动顺序是 `loadLangs() → refreshAll()`，保证首个请求就带上正确的 `lang` 与 `kind`。

> 分页曾出现「点下一页莫名跳到详情」的假象：根因是 `detail()` 在 `fetch` 返回后调 `box.scrollIntoView()`，
> 异步完成时用户已翻到下页，页面被强行滚回详情。现在详情改浮层且彻底去掉滚动。

## 5. 图标服务

`internal/icons/icons.go`：
- **按实体域取图**：`entityDomains`（`internal/icons/icons.go:34`）把物品限定在 `{Item, Character}`、NPC 在 `{Npc}`、怪物在 `{Mob}`，
  跨域不比较。`Path`/`Has`/`CopyTo`/`Serve` 都要传实体域（`internal/icons/icons.go:142` / `:173` / `:235` / `:179`）。
- `Build(dir)`（`internal/icons/icons.go:78`）**按来源自动分两种读法**：`dir` 是目录就遍历文件系统；
  是文件（`.zip`）就只解析 ZIP 中央目录建索引（`buildZip`，`internal/icons/icons.go:130`），
  两种来源建出来的索引 `(域, ID)` 完全一致，查询与路由不分叉。ID 经 `extract.NormalizeID` 零填充到 8 位后按域作键。
- 同域内同号多张按 `rankOf`（`internal/icons/icons.go:120`）取优先级（`Item`=0 > `Character`=1 > `Npc`=2 > `Mob`=3）；**跨域不再互相顶替**（修复前"其他"域参与物品取图，导致 1,578 个物品行挂上 NPC 立绘）。
- 路由 `/img/<id>.png?for=<kind>`（`Serve`，`internal/icons/icons.go:321`）：`for` 缺省即物品域，只接受纯数字 ID，路径一律取自索引，因此不存在目录穿越；非法名 400、无此图标 404，命中则带 `Cache-Control: public, max-age=86400`。
- `icons.enabled=false` 时 `web.New(db, cfg, nil)`，`/img` 根本不注册，页面也不渲染图标列——**关掉图标不影响任何数据**。
- 现状（实测）：`imgdata` 里没有 `Mob` 目录，故怪物域 0 张图；Npc 域有图、物品域有图。见 [11-NPC与怪物解析](11-NPC与怪物解析.md)。

### zip 来源的读取方式

`icons.dir` 指到 `imgdata.zip` 时（`read`，`internal/icons/icons.go:224`）：

- **Store 模式条目走 `io.SectionReader` 按偏移直读**，绕开 `flate` 包装器，不额外分配解压对象；
  判据是 `Method == Store` **且** `CompressedSize64 == UncompressedSize64`，任一不满足（比如用 deflate 打包）
  就回退 `fh.Open()` 正常解压，绝不返回脏字节。
- 并发安全：`*os.File` 实现 `io.ReaderAt`，`SectionReader` 只做偏移量算术，多 goroutine 同时取图无竞争、不需要加锁。
- 单张声明大小超过 `maxImageSize`（8 MB，`internal/icons/icons.go:39`）的条目直接不索引，挡掉"解压炸弹"式的伪造中央目录。
- 打包时若多套一层目录（`Compress-Archive imgdata imgdata.zip` 会得到 `imgdata/Character/...`），
  `zipPrefix`（`internal/icons/icons.go:180`）在**所有条目共享同一首段且该首段不是已知域**时剥掉它，
  否则每张图都会被当成一个独立域；反斜杠条目名（老版 Compress-Archive 的写法）统一归一成 `/`。
- 换 zip 后必须重启 `serve`：索引只在启动时建，改包内容不会自动生效。

本机实测（28,504 张、`imgdata.zip` 35.6 MB）：zip 建索引 **75ms**（目录遍历要 1s 量级）、
单张读取均值 **58µs** 对目录 **598µs**（约 10 倍）、两边索引规模与逐字节内容完全一致。

## 6. 常见故障

| 现象 | 原因与处置 |
|---|---|
| `bind: Only one usage of each socket address` | 8080 上还有旧实例。`netstat -ano \| grep :8080` 取 PID 确认后停掉，或 `-addr 127.0.0.1:8081` 换端口 |
| 页面全碎图 | `icons.dir` 指错目录；启动日志会打印图标索引规模，为 0 即目录不对 |
| 某语言条目为 0 | 该 locale 的 `sources` 没覆盖到含物品 ID 的包，或 `wz` 目录指错 |
| 查询返回整表数据 | 前端把查询串拼错了（历史上曾把函数名序列化进 URL），核对 `collectParams()` |
| 管理页 401 | `admin.token` 非空但请求头没带上/带错；页面顶部重填口令 |
| 管理页 403 | 口令留空却从非回环地址访问；要么设 `token`，要么用 `127.0.0.1` 打开 |
| 用 curl 改库后中文变 `?`/乱码 | Windows 控制台是 GBK 代码页，命令行里的中文请求体在发出前就被改写成 U+FFFD。改用 `--data @文件`（文件以 UTF-8 落盘），并且写后按字节回读：`\| xxd` 看是不是 `efbfbd`。已经写坏的行走管理页"按文件重载"即可从 XML 恢复 |
| 重载后 `/api/admin/*` 报 409 | 已有一个后台任务在跑，等它结束或刷新看进度 |
| 明细里"库内 无记录"却重载不动 | 那是 `new` 态，勾选后走 `paths`，或用「重载新增+变更」 |
| 改了 `admin.html` 页面没变 | 前端是 `go:embed` 进二进制的，必须重新 `go build` 并重启服务 |
